## หน้าเว็บ

| ไฟล์ | คืออะไร |
|---|---|
| `index.html` | หน้าแรก — อนิเมชันตราครุฑ แล้วเดินชมหอภาพเหมือน |
| `website_new.html` | **ฉบับเว็บใหม่** — ดีไซน์ปัจจุบัน สร้างจาก `src/` ด้วยสคริปต์ |
| `website_constitution.html` | **ฉบับเว็บเดิม** — ไฟล์เดียวจบ แก้ด้วยมือ ยังใช้งานได้เต็มรูปแบบ |
| `world_map.html` | แผนที่โลกแบบโต้ตอบ ฝังอยู่ในแถบภูมิรัฐศาสตร์ |
| `404.html` | หน้าแจ้งเมื่อพิมพ์ที่อยู่ผิด |

## โครงสร้างโฟลเดอร์

```
src/            ต้นฉบับของเว็บใหม่ — hub.json + tabs/*.html + head/tail
tools/          build_site.py (ตัวสร้างเว็บใหม่), site_template.html, relayout.py, detone.py
css/            site.css (เว็บใหม่), constitution.css (ใช้ร่วมกัน)
js/             constitution.js, site.js, glossary-data.js, portrait-hall.js, hall-data.js
images/         ภาพเหมือน ตราสัญลักษณ์ โลโก้พรรค ธง และภาพประกอบ
audio/          เพลงประจำพรรคและเพลงประจำชาติ
```

## สร้างเว็บใหม่

`website_new.html` เป็นไฟล์ที่ **สคริปต์สร้างขึ้น** — อย่าแก้ด้วยมือ ให้แก้ที่ `src/` แล้วสั่ง

```bash
python tools/build_site.py
```

ส่วน `website_constitution.html` แก้ด้วยมือโดยตรง เป็นไฟล์เดียวขนาดประมาณ ๖ MB

### หลังแก้ไขทุกครั้ง

1. ตรวจโครงสร้าง `<div>` ด้วยการเดิน stack — ผลที่ถูกต้องคือ
   `unclosed 2 | stray 0 | panels 68 | overlaps [] | buttons == panels`
   (`unclosed 2` เป็นเรื่องปกติ: `dashboard-card` กับ `preamble-section` ปล่อยเปิดค้างถึงท้ายไฟล์)
2. ถ้าแก้ไฟล์ใน `css/` หรือ `js/` ต้องเลื่อนเลข `?v=` ใน **ทั้ง** `website_constitution.html`
   และ `tools/site_template.html` ไม่งั้นเบราว์เซอร์จะยังใช้ของเก่าที่แคชไว้

> ⚠️ จำนวน `<div>` ที่เท่ากันไม่ได้แปลว่าโครงสร้างถูก — ความเสียหายที่เจอบ่อยที่สุดในไฟล์นี้
> คือปิดแท็กครบแต่ซ้อนผิดชั้น ซึ่งทำให้เนื้อหาไปโผล่ผิดแถบ ต้องตรวจด้วย overlap check เท่านั้น

## หมายเหตุเรื่องเนื้อหา

- เนื้อหาบางส่วนอ้างอิงเหตุการณ์และบุคคลจริง แต่ถูกดัดแปลงให้อยู่ในเส้นเวลาสมมติ
- บล็อกไว้อาลัยที่ด้านบนสุดของหน้าเป็นเรื่องจริง ไม่ใช่ส่วนหนึ่งของโลกสมมติ
- เว็บไม่เก็บข้อมูลผู้ใช้ ไม่มีระบบสมาชิก ทำงานเป็นไฟล์สแตติกล้วน
