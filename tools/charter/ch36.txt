# หมวด ๓๖ บทลงโทษและมาตรการบังคับตามรัฐธรรมนูญ (ม.๑๐๙๑-๑๑๒๗; ม.๑๑๒๘-๑๑๒๙ คงเดิม)
# 0 โทษเจ้าหน้าที่ที่จงใจละเมิดรัฐธรรมนูญ
0.1|ประชาชนย่อมมีสิทธิได้รับการคุ้มครองจากการใช้อำนาจรัฐที่ฝ่าฝืนรัฐธรรมนูญ เจ้าหน้าที่ของรัฐผู้ใดจงใจปฏิบัติหรือละเว้นการปฏิบัติหน้าที่อันเป็นการละเมิดสิทธิหรือเสรีภาพที่รัฐธรรมนูญรับรอง ต้องรับโทษทางวินัยถึงขั้นไล่ออก และต้องระวางโทษจำคุกตามที่กฎหมายบัญญัติ
0.2|ให้ผู้ตรวจการแผ่นดินของรัฐสภามีอำนาจไต่สวนเจ้าหน้าที่ของรัฐที่ถูกกล่าวหาว่ากระทำการตามมาตรา ๑๐๙๑ และส่งสำนวนให้ผู้บังคับบัญชาลงโทษทางวินัยภายในเวลาที่กำหนด และส่งให้อัยการสูงสุดฟ้องคดีอาญา
0.3|ให้มีกองทุนช่วยเหลือผู้เสียหายจากการละเมิดรัฐธรรมนูญ เพื่อจ่ายค่าเสียหายเบื้องต้นแก่ผู้เสียหายโดยไม่ต้องรอผลคดี และให้รัฐไล่เบี้ยเอาจากเจ้าหน้าที่ผู้กระทำการโดยจงใจภายหลัง
0.4|ผู้เสียหายย่อมมีสิทธิร้องเรียนต่อผู้ตรวจการแผ่นดินของรัฐสภาตามมาตรา ๑๐๙๙ หรือฟ้องคดีต่อศาลโดยตรง และมีสิทธิได้รับแจ้งความคืบหน้าของการดำเนินการ
0.5|ในการลงโทษตามมาตรา ๑๐๙๑ ต้องพิจารณาความรับผิดของผู้บังคับบัญชาที่สั่งการหรือรู้แล้วไม่ยับยั้งด้วย และผู้ใต้บังคับบัญชาจะอ้างคำสั่งผู้บังคับบัญชาเป็นข้อแก้ตัวมิได้
# 1 โทษผู้ก่อการรัฐประหาร
1.1|รัฐต้องรับรองหลักการว่าผู้ก่อการ หัวหน้า และผู้สั่งการในการทำรัฐประหารหรือลบล้างรัฐธรรมนูญ ต้องระวางโทษตามมาตรา ๑๑๖๐ ส่วนผู้สนับสนุน ผู้ให้ความช่วยเหลือ และผู้ที่รับตำแหน่งจากคณะรัฐประหารโดยรู้ว่าเป็นการยึดอำนาจโดยมิชอบ ต้องระวางโทษจำคุกตลอดชีวิต
1.2|ให้อัยการสูงสุดมีหน้าที่ฟ้องคดีตามมาตรา ๑๐๙๒ ต่อศาลฎีกาโดยตรงทันทีที่การปกครองตามรัฐธรรมนูญกลับคืนมา และจะใช้ดุลพินิจสั่งไม่ฟ้องมิได้
1.3|รัฐต้องจัดสรรงบประมาณสำหรับการรวบรวมและเก็บรักษาพยานหลักฐานการยึดอำนาจไว้อย่างปลอดภัย รวมทั้งสำเนาที่เก็บไว้นอกราชอาณาจักร เพื่อใช้ในการดำเนินคดีตามมาตรา ๑๐๙๒
1.4|หน่วยงานของรัฐต้องเปิดเผยรายชื่อผู้ถูกดำเนินคดีตามมาตรา ๑๐๙๒ ความคืบหน้าของคดี และคำพิพากษาต่อสาธารณะ
1.5|ให้รัฐร่วมมือกับต่างประเทศและองค์การระหว่างประเทศในการติดตามตัวผู้กระทำความผิดตามมาตรา ๑๐๙๒ ที่หลบหนีไปนอกราชอาณาจักร และอายัดทรัพย์สินของบุคคลดังกล่าว
# 2 บังคับใช้คำวินิจฉัยขององค์กรตรวจสอบ
2.1|ประชาชนย่อมมีสิทธิได้รับผลจากคำวินิจฉัยขององค์กรตรวจสอบที่คุ้มครองสิทธิของตน คำวินิจฉัยของศาลรัฐธรรมนูญ ศาลปกครอง และคำสั่งขององค์กรอิสระที่ให้คุ้มครองสิทธิ มีผลผูกพันหน่วยงานของรัฐทันที และหน่วยงานจะอ้างเหตุใดเพื่อชะลอการปฏิบัติมิได้
2.2|ให้มีหน่วยงานติดตามการปฏิบัติตามคำวินิจฉัย ทำหน้าที่ตรวจสอบว่าหน่วยงานของรัฐได้ปฏิบัติตามคำวินิจฉัยตามมาตรา ๑๐๙๓ ภายในเวลาที่กำหนดหรือไม่ และรายงานหน่วยงานที่ไม่ปฏิบัติต่อรัฐสภา
2.3|ให้มีกองทุนบังคับการตามคำวินิจฉัย เพื่อจ่ายค่าเสียหายแก่ผู้ได้รับความคุ้มครองแทนหน่วยงานที่ไม่ปฏิบัติตามคำวินิจฉัย และหักคืนจากงบประมาณของหน่วยงานนั้นในปีถัดไป
2.4|ผู้ได้รับความคุ้มครองตามคำวินิจฉัยย่อมมีสิทธิร้องขอต่อหน่วยงานตามมาตรา ๑๑๐๑ ให้บังคับการ เมื่อหน่วยงานของรัฐไม่ปฏิบัติตามคำวินิจฉัยภายในเวลาที่กำหนด
2.5|ให้หน่วยงานตามมาตรา ๑๑๐๑ มีอำนาจระงับการเบิกจ่ายงบประมาณบางส่วนของหน่วยงานที่ไม่ปฏิบัติตามคำวินิจฉัย และสืบสวนเจ้าหน้าที่ผู้รับผิดชอบเพื่อดำเนินการทางวินัย
# 3 ริบทรัพย์ย้อนหลังผู้ทุจริต
3.1|รัฐต้องรับรองหลักการว่าทรัพย์สินและสิทธิประโยชน์ที่ได้มาจากการทุจริตต่อหน้าที่หรือการฝ่าฝืนบทบัญญัติแห่งรัฐธรรมนูญ ต้องถูกริบคืนแผ่นดินไม่ว่าจะตกไปอยู่กับผู้ใด เว้นแต่ผู้รับโอนโดยสุจริตและเสียค่าตอบแทน
3.2|ให้คณะกรรมการติดตามทรัพย์สินคืนแผ่นดินตามมาตรา ๖๗๓ มีอำนาจติดตามทรัพย์สินตามมาตรา ๑๐๙๔ ย้อนหลังไปจนถึงวันที่ได้มา โดยไม่มีอายุความ
3.3|ทรัพย์สินที่ริบได้ตามมาตรา ๑๐๙๔ ให้นำเข้ากองทุนต่อต้านการทุจริตภาคประชาชนตามมาตรา ๑๑๕๘
3.4|หน่วยงานของรัฐต้องเปิดเผยรายการทรัพย์สินที่ริบได้ตามมาตรา ๑๐๙๔ และการนำไปใช้ประโยชน์ต่อสาธารณะ
3.5|กฎหมายว่าด้วยการริบทรัพย์สินตามมาตรา ๑๐๙๔ ต้องได้รับการทบทวนทุกห้าปี เพื่อปิดช่องทางการโอนทรัพย์สินผ่านนิติบุคคลและผู้ถือแทน
# 4 พักงานนักการเมืองที่ส่อเจตนาฝ่าฝืน
4.1|ประชาชนย่อมมีสิทธิขอให้ผู้ดำรงตำแหน่งทางการเมืองที่มีพยานหลักฐานอันควรเชื่อว่าจงใจใช้อำนาจละเมิดสิทธิของประชาชนอย่างร้ายแรง หยุดปฏิบัติหน้าที่ไว้ก่อนในระหว่างการไต่สวน
4.2|ให้ศาลรัฐธรรมนูญมีอำนาจสั่งให้ผู้ดำรงตำแหน่งทางการเมืองตามมาตรา ๑๐๙๕ หยุดปฏิบัติหน้าที่ไว้ก่อน เมื่อมีคำร้องจากสมาชิกรัฐสภาไม่น้อยกว่าหนึ่งในสิบหรือจากองค์กรอิสระ และต้องวินิจฉัยคำร้องให้แล้วเสร็จภายในสามสิบวัน
4.3|รัฐต้องจัดสรรงบประมาณให้องค์กรอิสระที่ไต่สวนกรณีตามมาตรา ๑๐๙๕ อย่างเพียงพอ เพื่อให้การไต่สวนแล้วเสร็จโดยเร็วและไม่ปล่อยให้การหยุดปฏิบัติหน้าที่ยืดเยื้อ
4.4|ประชาชนย่อมมีสิทธิทราบเหตุผลของคำสั่งให้หยุดปฏิบัติหน้าที่และผลการไต่สวน และคำสั่งดังกล่าวต้องเผยแพร่ต่อสาธารณะ
4.5|การใช้มาตรการตามมาตรา ๑๐๙๕ ต้องคำนึงถึงสิทธิในการต่อสู้คดีของผู้ถูกกล่าวหา และจะใช้เป็นเครื่องมือทางการเมืองเพื่อขัดขวางรัฐบาลโดยไม่มีพยานหลักฐานมิได้ ผู้ยื่นคำร้องอันเป็นเท็จโดยรู้อยู่ต้องรับผิด
# 5 ฟ้องละเมิดทางแพ่งคืนสู่กองทุนประชาชน
5.1|รัฐต้องรับรองหลักการว่าความเสียหายที่เกิดแก่รัฐจากการกระทำของผู้ดำรงตำแหน่งทางการเมืองหรือเจ้าหน้าที่ของรัฐโดยจงใจหรือประมาทเลินเล่ออย่างร้ายแรง ต้องได้รับการชดใช้คืน และหน่วยงานของรัฐต้องฟ้องเรียกค่าเสียหายภายในเวลาที่กฎหมายกำหนด
5.2|ให้อัยการสูงสุดมีหน้าที่ฟ้องคดีตามมาตรา ๑๐๙๖ แทนหน่วยงานของรัฐที่ไม่ดำเนินการภายในเวลาที่กฎหมายกำหนด และให้ประชาชนจำนวนไม่น้อยกว่าหนึ่งหมื่นคนเข้าชื่อขอให้อัยการสูงสุดดำเนินการได้
5.3|เงินค่าเสียหายที่ได้รับชดใช้ตามมาตรา ๑๐๙๖ ในส่วนที่เกิดจากการทุจริต ให้นำเข้ากองทุนต่อต้านการทุจริตภาคประชาชนตามมาตรา ๑๑๕๘ เพื่อเยียวยาผู้ได้รับผลกระทบ
5.4|หน่วยงานของรัฐต้องเปิดเผยรายการความเสียหายที่ได้ฟ้องเรียก ผลคดี และจำนวนเงินที่ได้รับชดใช้ตามมาตรา ๑๐๙๖ ต่อสาธารณะ
# 6 คดีแบบกลุ่ม
6.1|ผู้เสียหายจากการปฏิบัติงานของรัฐย่อมมีสิทธิฟ้องคดีแบบกลุ่ม เพื่อให้ผู้เสียหายจำนวนมากที่ได้รับความเสียหายจากเหตุเดียวกันได้รับการเยียวยาในคดีเดียว โดยไม่ต้องฟ้องเป็นรายบุคคล
6.2|ให้ศาลยุติธรรมและศาลปกครองจัดให้มีกระบวนการพิจารณาคดีแบบกลุ่มที่สะดวก รวดเร็ว และให้ทนายความผู้แทนกลุ่มได้รับค่าตอบแทนจากค่าเสียหายตามที่ศาลกำหนด
6.3|รัฐต้องจัดสรรงบประมาณสำหรับการช่วยเหลือทางกฎหมายแก่กลุ่มผู้เสียหายที่มีรายได้น้อยในการฟ้องคดีแบบกลุ่มต่อหน่วยงานของรัฐ
6.4|ผู้เสียหายที่อยู่ในกลุ่มย่อมมีสิทธิได้รับแจ้งการฟ้องคดี และมีสิทธิขอออกจากกลุ่มเพื่อฟ้องคดีของตนเอง
# 7 สิทธิประชาชนฟ้องผู้สืบทอดอำนาจรัฐประหาร
7.1|ประชาชนย่อมมีสิทธิฟ้องคดีอาญาต่อผู้ที่สืบทอดหรือใช้อำนาจที่ได้มาจากการรัฐประหาร ในความผิดที่กระทำโดยอาศัยอำนาจนั้น และคดีดังกล่าวไม่มีอายุความ
7.2|ให้ศาลฎีกามีอำนาจรับฟ้องคดีตามมาตรา ๑๐๙๘ จากประชาชนโดยตรง เมื่ออัยการสูงสุดไม่ฟ้องภายในเวลาที่กฎหมายกำหนด และบทบัญญัติแห่งกฎหมาย ประกาศ หรือคำสั่งใดที่นิรโทษกรรมการกระทำดังกล่าว ไม่มีผลใช้บังคับ
7.3|รัฐต้องจัดสรรงบประมาณสำหรับความช่วยเหลือทางกฎหมายและการคุ้มครองพยานแก่ประชาชนที่ฟ้องคดีตามมาตรา ๑๐๙๘
7.4|หน่วยงานของรัฐต้องเปิดเผยประกาศ คำสั่ง และเอกสารราชการทั้งหมดที่ออกในระหว่างการยึดอำนาจ เพื่อใช้เป็นพยานหลักฐานในคดีตามมาตรา ๑๐๙๘
