ฝ่ายค้านใหม่และการเลือกตั้งซ่อม ๓๑ ธันวาคม ๒๗๓๒

วิกฤตภาพลวงสู่การเลือกตั้งซ่อมครั้งประวัติศาสตร์ — จากภาพปลอมที่ทำให้ฝ่ายค้านฟ้าน้ำเงินเหลืองแตกกันเอง สู่ญัตติถอดถอน ส.ส. ฝ่ายค้านทั้งหมด และการเลือกตั้งซ่อม ๘๗ ที่นั่งในวันรัฐธรรมนูญ ที่ทำให้ขั้วฟ้าน้ำเงินเหลืองหายไปจากสภา

๘๗ ที่นั่งเลือกใหม่ทั้งหมด (เขต ๖๔ + บัญชีรายชื่อ ๒๓)
๔๑๓ / ๘๗รัฐบาลส้มแดง / ฝ่ายค้านใหม่ หลังเลือกตั้งซ่อม
๐ ที่นั่งขั้วฟ้าน้ำเงินเหลืองเดิม — สูญพันธุ์จากสภา
๒๔ ที่นั่งไทยรักษาชาติ — มากที่สุดในฝ่ายค้านใหม่
๔๔๕–๐–๕๕ร่างกฎหมายที่ผ่านสภาขณะฝ่ายค้าน "เงียบ"
๓๑ ธ.ค. ๒๗๓๒วันเลือกตั้งซ่อม — วันรัฐธรรมนูญ

🎭 ช่วงที่ ๑ — การโจมตีด้วยภาพปลอม

เหตุการณ์รายละเอียด
ภาพแรกโลโก้ "รัฐบาลฟ้าน้ำเงินเหลือง" ถูกฉีกเป็นรอยแตก แยกเสรีรวมไทยออกจากพันธมิตร
การซูมรายละเอียดตัว "อง" ในคำว่า "เหลือง" ถูกทำให้มืดลง สื่อว่าเสรีรวมไทยกำลังแยกตัว
บัญชีถูกลบก่อนหาย ทิ้งข้อความว่าโดนคนในพรรคตัวเองสั่งให้ลบ (ไม่บอกชื่อพรรค)
ภาพที่ ๒โลโก้เสรีรวมไทยถูกบิดเป็น "รวมพลังทำลายชาติ" / "พรรคขายชาติเสรี"
ภาพที่ ๓โลโก้ความหวังใหม่ถูกบิดเป็น "Collapsing Hope Party" / "พรรคความหวังพังทลาย"
ภาพที่ ๔–๕ประชาธิปัตย์ → "ประชาตะบัดสัตย์ / Cowardly Party" · รวมไทยสร้างชาติ → "รวมชาติพังทลาย"
โพสต์เฉลยบัญชีกลับมาพร้อมภาพสรุปทั้ง ๔ พรรค เขียนว่า "พรรคปัญญาอ่อน" และสารภาพว่า "อยู่ฝ่ายค้านเอง"

🥊 ช่วงที่ ๒ — ความแตกแยกภายในฝ่ายค้าน

  • สมาชิกพรรคต่าง ๆ ทะเลาะและเกือบชกต่อยกันในโรงอาหารสภา
  • ทีมสืบสวนร่วมพบว่าบัญชีทั้ง ๔ เชื่อมเซิร์ฟเวอร์เดียวกัน ทำให้สงสัยว่าเป็นการร่วมมือกันของคนใน ๔ พรรค
  • ฝ่ายค้านเข้าสู่ภาวะ "เงียบ" ไม่มีใครกล้าอภิปราย ปล่อยผ่านร่างกฎหมายโดยไม่ตรวจสอบ (๔๔๕–๐–๕๕)
  • รัฐบาลต้องตั้ง "คณะกรรมการตรวจสอบนโยบายภายในพรรคร่วมรัฐบาล" ทำหน้าที่ฝ่ายค้านแทนตัวเอง

💔 ช่วงที่ ๓ — จุดแตกหักส่วนตัว

เหตุการณ์ผล
ธีรภัทร (ภัทร) เสนอทางออกโครงการโครงสร้างพื้นฐาน แต่พรรคเสรีรวมไทยเลือกค้านทั้งหมดจุดเริ่มความผิดหวัง
ภัทรลาออกจากเสรีรวมไทย เข้าพรรคก้าวไกลต้องสังกัดพรรคใหม่ ๙๐ วันก่อนลงเลือกตั้งซ่อมได้
ส.ส. เขตคนใหม่ป่วยลาออกที่วันที่ ๘๕เปิดช่องให้ภัทรลงสมัครได้พอดีที่วันที่ ๑๓๐ และชนะ
ที่นั่งสภาขยับรัฐบาล ๔๑๒ → ๔๑๓ / ฝ่ายค้าน ๘๘ → ๘๗
อะตอมตำหนิบัญญัติกลางสภาเรื่องไม่ฟังภัทร บัญญัติแก้ตัวว่าแต่ละพรรคมีกระบวนการต่างกันอะตอมเตือนว่าไม่มีใครรับรองญัตติของภัทรเลยสักคน
บัญญัติขอคำปรึกษาซ้ำ ๆ แต่ไม่นำไปปฏิบัติจริงอะตอมบล็อกเบอร์ ตัดขาดความสัมพันธ์ ประกาศเป็นคู่แข่งทางการเมืองที่แท้จริง

🔍 ช่วงที่ ๔ — การเปิดเผยความจริง (๓ เดือนก่อนหน้า แต่ไม่มีใครสนใจ)

  • ผู้กระทำผิดทั้ง ๔ คนถูกจับได้จริงตั้งแต่ ๓ เดือนก่อน
  • ไม่ใช่คนในพรรคใดเลย — เป็นอดีตพนักงานบริษัทที่ปรึกษาการตลาดการเมือง รับจ้างจากกลุ่มธุรกิจที่ต้องการเห็นความไร้เสถียรภาพทางการเมือง
  • ความเสียหายที่เกิดขึ้นแล้ว (ภัทรย้ายพรรค, อะตอม–บัญญัติแตกคอ) ไม่มีทางย้อนกลับ

⚖️ ช่วงที่ ๕ — ญัตติถอดถอนประวัติศาสตร์

ขั้นตอนรายละเอียด
ภัทรเปิดอภิปรายด้วยท่อนหนึ่งจากเพลง "ก้าวไกลก้าวหน้า"สร้างความสั่นสะเทือนทั้งสภา
เสนอถอดถอน ส.ส. ฝ่ายค้านทั้งหมดที่โหวตไม่เห็นด้วยแบบไม่มีเหตุผลให้จัดเลือกตั้งซ่อมทุกเขต
บัญญัติค้าน ภัทรตอบโต้: "ให้ประชาชนตัดสินสิ…หรือที่พวกท่านไม่กล้า เพราะรู้อยู่แล้วว่าอำนาจอันศักดิ์สิทธิ์ของประชาชนนี้จะไม่เลือกพวกท่าน"สร้างความเงียบทั้งสภา
กำหนดโหวตภายใน ๗ วัน (ขั้นต่ำ ๓ วัน)แสดงความเมตตาในระดับหนึ่ง
วันโหวต: ฝ่ายค้านเตรียมแต่กระดาษแก้ตัวเรื่องถอดถอน ไม่พูดเรื่องประชาชนเลยทั้งเช้า ขณะที่รัฐบาลเตรียมข้อมูลมาเต็มที่ทั้งที่ไม่ใช่ฝ่ายถูกกล่าวหาภัทรฉีกกระดาษโต้ตอบของตัวเองทิ้ง เพราะไม่จำเป็นต้องใช้แล้ว
รัฐบาลประกาศจะไม่ส่งผู้สมัครลงแข่งในเขตที่ถูกถอดถอนเปิดทางให้พรรคอื่นเข้ามาแทน

📊 ช่วงที่ ๖ — ผลการเลือกตั้งซ่อม ๓๑ ธันวาคม ๒๗๓๒

จำนวนที่นั่งที่เลือกใหม่ทั้งหมด ๘๗ ที่นั่ง (เขต ๖๔ + บัญชีรายชื่อ ๒๓) — ไม่ใช่ ๘๘ เพราะหลังภัทรย้ายจากเสรีรวมไทยไปก้าวไกล ที่นั่งเขตของเขาถูกโอนไปฝั่งรัฐบาลแล้วตั้งแต่ตอนนั้น ฝ่ายค้านเดิมจึงเหลือ ๘๗ ที่นั่งก่อนถูกถอดถอนทั้งหมด
